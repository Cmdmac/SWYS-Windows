# SWYS-Windows · 语音控制台

> Windows 系统的「可见可说」文本/语音控制系统 —— 用一句话或一句语音，让电脑帮你点按钮、开应用、关窗口、关标签页、调音量……

SWYS-Windows 是一个运行在 Windows 上的**桌面控制控制台**。它把你说的自然语言（或手打的文字）翻译成对这台电脑的具体操作：打开应用、点击屏幕上某个按钮、操作窗口、控制音量、关闭浏览器标签页、甚至把一句复杂指令交给大模型拆解成多步动作后逐步执行。

整个系统以「**可见可说**」为核心设计理念：

- **可见** —— 屏幕上你能看到的控件 / 菜单名，直接说出口就能操作（用 UI 自动化按名称定位；自绘控件识别不到时自动回退到 OCR 按屏幕文字点击）。
- **可说** —— 操作结果可以用语音播报出来（Windows 自带语音，离线可用，无需联网）。

## 核心特性

- 🎙 **语音 + 文字双入口**：底部输入框手打指令，或点 🎤 用麦克风说话（需联网 + 麦克风）。
- ⚡ **简单指令零依赖直执行**：打开应用、截图、锁屏、音量、窗口操作、时间日期、进入目录、鼠标点击/滚动、关闭浏览器标签页等，**不需要联网、不需要大模型**，本地直接执行。
- 🧠 **复杂指令交给大模型**：一句话说不清的多步任务（如「把音量调大两格再打开记事本写一段待办」），自动调用兼容 OpenAI 接口的大模型拆成动作步骤后执行。
- 👁 **可见可说 / 控件语音点击**：
  - 本程序自身按钮（发送 / 清空 / 演练 / 语音 / 设置 / 帮助 / 麦克风）是语义动作，说出即执行。
  - 其它应用的常用动作（保存 / 复制 / 粘贴 / 撤销 / 编辑 / 文件 / 打印…）直接向**前台窗口**发送对应快捷键（如 `Ctrl+S` / `Ctrl+C` / `Alt+E`），无需 OCR，更快更稳。
  - 其它应用的其它控件 / 按钮名：用 **UI 自动化（uiautomation）** 按名称定位并点击；若控件没暴露可访问名称（如部分自绘按钮），自动改用 **OCR（Tesseract）** 识别屏上中文后按坐标点击。
- 📱 **局域网远程控制**：内置 HTTP 服务，手机 / 另一台电脑的浏览器打开即可发指令；也支持用脚本 POST 调用，方便接入自动化。
- 🔒 **危险操作保护**：关机 / 重启 / 睡眠等危险指令默认弹二次确认；局域网侧默认**禁止**触发危险操作（`allow_destructive=false`），可显式开启。
- 🗂 **系统托盘 + 单实例**：最小化到托盘、重复双击只唤起已有窗口；双击 `launch.vbs` 即可无黑窗口静默启动。

## 工作原理

```
┌──────────────────────────────────────────────────────────┐
│  输入层：GUI 输入框 / 🎤 麦克风 / 局域网 HTTP 控制页        │
└───────────────────────────┬──────────────────────────────┘
                            ▼
┌──────────────────────────────────────────────────────────┐
│  simple.py —— 指令理解                                      │
│   · 直接指令 → 本地规则匹配（无需联网）                      │
│   · 复杂指令 → 交给 llm.py 调用大模型拆成 steps             │
└───────────────────────────┬──────────────────────────────┘
                            ▼
┌──────────────────────────────────────────────────────────┐
│  actions.py —— 动作执行（execute_steps）                   │
│   打开应用 / 文件 / URL · 窗口操作 · 音量 · 截图 ·          │
│   鼠标键盘 · 按名点击(UIA) / OCR点击 · 进入目录 · 关标签页  │
└───────────────────────────┬──────────────────────────────┘
                            ▼
┌──────────────────────────────────────────────────────────┐
│  winctl.py —— Windows 控制底层（ctypes + Pillow 兜底）      │
│   枚举窗口 / 激活前台窗口 / 发送按键 / 取窗口类名           │
└──────────────────────────────────────────────────────────┘
```

- **语音输入（STT）**：`stt.py` 通过麦克风 + Google 语音识别（需联网、需 `pyaudio`）；未安装时自动降级，不影响其它功能。
- **语音播报（TTS）**：`tts.py` 使用 Windows 自带 SAPI5（`pyttsx3`），**离线**朗读中文。
- **大模型分析**：`llm.py` 兼容 OpenAI / Azure OpenAI / 本地 Ollama 等 OpenAI 格式接口，把自然语言拆成动作 JSON。

## 快速开始

### 环境要求

- Windows 系统（程序使用 `ctypes` / `win32` 调用，仅限 Windows）
- Python 3.8+（首次运行会自动创建 `venv` 虚拟环境）
- 可选：麦克风（`pyaudio`）+ Tesseract-OCR 引擎（用于中文 OCR 点击）

### 安装依赖

```bash
pip install -r requirements.txt
```

依赖均为纯 Python 或有预编译 wheel，**普通 pip 一次装好，无需编译、无需管理员**。`pyautogui` 不再强制依赖（已内置 `winctl` ctypes 兜底）。

### 启动

```bash
python main.py
# 或双击 run.bat（会自动建 venv 并装依赖）
# 或双击 launch.vbs（静默启动，无黑色控制台窗口；可在桌面建快捷方式）
```

启动后建议先点窗口里的「?」查看完整用法，复杂指令前先点「🧪演练」模式（只解析不执行，安全试错）。

### 可选组件

- **麦克风语音输入（🎤）**：`pip install pipwin && pipwin install pyaudio`（推荐，省去编译）；或装好 VC++ 构建工具后 `pip install pyaudio`。
- **OCR 屏幕点击**：运行本项目附带的 `install_tesseract.bat`（右键「以管理员身份运行」，已含中文语言包 `chi_sim`）；或在 `config.json` 中设置 `"tesseract_path": "C:/path/to/tesseract.exe"`。

## 配置说明（config.json）

首次运行会自动生成 `config.json`，也可在 GUI 点「⚙」修改。关键字段：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `endpoint` | `https://api.openai.com/v1` | 大模型接口地址（兼容 OpenAI / Azure / Ollama） |
| `api_key` | 空 | API Key（留空则复杂指令不可用，但所有直接指令照常） |
| `model` | `gpt-4o-mini` | 使用的模型名 |
| `auto_speak` | `true` | 是否自动语音播报结果 |
| `speech_rate` | `170` | 语音语速 |
| `language` | `zh-CN` | 语音识别语言 |
| `confirm_destructive` | `true` | 危险操作（关机/重启/睡眠）前二次确认 |
| `tesseract_path` | 空 | Tesseract 引擎路径（留空自动找便携版/PATH） |
| `http_control.enabled` | `true` | 是否开启局域网 HTTP 控制 |
| `http_control.port` | `8765` | HTTP 控制端口 |
| `http_control.allow_destructive` | `false` | 是否允许**局域网**触发危险操作（默认禁止） |
| `http_control.https_enabled` | `true` | 是否同时开启 HTTPS（「按住说话」的麦克风需 HTTPS 页面） |
| `http_control.https_port` | `8766` | HTTPS 控制端口 |
| `http_control.asr_proxy_port` | `8767` | ASR WebSocket 中转端口（与控制台同证书） |
| `http_control.asr_ws_url` | `wss://192.168.0.103:8443/asr` | FunASR 语音识别后端地址 |
| `tray.enabled` | `true` | 是否启用系统托盘 |
| `tray.start_minimized` | `false` | 启动后是否直接最小化到托盘 |

配置采用**深度合并**加载：你只写改动的字段，缺失字段自动用默认值补齐，不会因为覆盖整段而丢失 `http_control` / `tray` 等设置。

## 局域网控制 & 手机端

程序启动后默认开启局域网 HTTP 控制服务，点界面「🌐」可查看本机地址、curl / Python 调用示例与复制按钮。

- **控制页（HTTP）**：`http://<本机局域网IP>:8765` —— 手机或其它电脑浏览器打开即可发文字指令。
- **控制页（HTTPS）**：`https://<本机局域网IP>:8766` —— 提供「**按住说话**」麦克风入口（浏览器仅允许 HTTPS 页面调用麦克风）。
  - 使用自签名证书，首次打开浏览器会提示「不安全」，点「高级 → 继续访问」信任一次即可（证书 SAN 已包含 `localhost` 与当前局域网 IP，首次启动自动生成于 `certs/`）。
- **ASR 语音识别中转**：手机端浏览器无法信任 FunASR 自签名证书，因此控制页的「按住说话」经由本机 `:8767` 中转（复用控制台证书）转发到 FunASR 后端 `wss://192.168.0.103:8443/asr`，手机只需信任控制台这一张证书。

### 接口示例

```bash
# 发送一条指令
curl -X POST http://<本机IP>:8765/api/command -H "Content-Type: application/json" -d "{\"text\":\"打开记事本\"}"

# 查询最近对话日志
curl http://<本机IP>:8765/api/log
```

> ⚠️ 局域网侧的关机 / 重启 / 睡眠等危险操作默认被拦截（`allow_destructive=false`），如需开放请在 `config.json` 中显式设为 `true`。

## 安全说明

- **自签名证书**仅用于局域网 HTTPS 控制页，便于手机调用麦克风；请勿在公网暴露这些端口。
- **危险操作门禁**：本机侧默认二次确认；局域网侧默认完全禁止触发危险操作。
- **私钥不入库**：`certs/` 下的证书私钥、测试截图等已写入 `.gitignore`，不会随源码提交。
- 程序以当前用户权限运行，能做的事情等同于你本人能做的操作（打开应用、模拟键鼠等），请仅在可信网络环境下开启局域网控制。

## 项目结构（主要文件）

| 文件 | 职责 |
| --- | --- |
| `main.py` | Tkinter 主界面、指令调度、系统托盘、单实例保护 |
| `simple.py` | 指令理解：直接指令规则匹配（`GENERIC_ACTIONS` / `APP_COMMANDS` / 关标签页路由等） |
| `actions.py` | 动作执行：`execute_steps`、窗口操作、按名点击、进入目录、关闭标签页等 |
| `winctl.py` | Windows 控制底层（枚举窗口、激活、发键、取窗口类名），ctypes + Pillow 兜底 |
| `llm.py` | 复杂指令分析，兼容 OpenAI 格式接口 |
| `stt.py` | 语音输入（麦克风 + Google 识别，可降级） |
| `tts.py` | 语音播报（SAPI5 / pyttsx3，离线） |
| `http_control.py` | 局域网 HTTP/HTTPS 控制服务 + ASR 中转 + 自签名证书生成 |
| `web_control.html` | 局域网控制页（按住说话、快捷指令，单文件 HTML） |
| `config.py` / `config.json` | 配置管理与用户配置（深度合并） |
| `tray.py` | 系统托盘图标与菜单 |
| `launch.vbs` / `run.bat` / `bootstrap.py` | 启动链：静默启动 → 自动建 venv → 捕获启动异常并弹窗 |

启动链：`launch.vbs` → `run.bat`（静默）→ `pythonw bootstrap.py` → `main.main()`（无控制台窗口；启动期异常写入 `voice_control_error.log` 并弹窗）。

## 常见问题

- **双击没反应？** 先看 `launch_trace.log` / `voice_control_error.log` 是否有报错；程序默认走托盘，可能已最小化到右下角，点托盘图标即可显示。
- **🎤 麦克风用不了？** 需要先装 `pyaudio`（见上方可选组件）；程序会自动检测并提示原因。
- **某些按钮点不到？** 若控件没有可访问名称，程序会自动改用 OCR（Tesseract）按屏上文字点击，请确保已安装 Tesseract 与中文包。
- **复杂指令提示「未配置 Key」？** 在「⚙」填写 `endpoint` / `api_key` / `model` 后即可使用；所有直接指令无需 Key 也能用。
- **手机端「按住说话」连不上？** 确认手机和电脑在同一局域网，且用 **HTTPS**（`https://<IP>:8766`，非 http）打开控制页，并信任自签名证书。
